# Exercícios de Java — Geração Caldeira

Este repositório reúne exercícios e desafios de programação desenvolvidos durante meus estudos de Java no Geração Caldeira.

O objetivo é praticar a lógica de programação, aprimorar meus conhecimentos na linguagem Java e acompanhar minha evolução como desenvolvedor.

## Organização

Os exercícios estão organizados em três níveis de dificuldade:

- **Básico:** exercícios introdutórios.
- **Médio:** exercícios de nível intermediário.
- **Avançado:** desafios de maior complexidade.

## Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git e GitHub

## Objetivo

Desenvolver minhas habilidades em programação, fortalecer minha capacidade de resolução de problemas e construir uma base sólida para minha carreira na área de tecnologia.

Este repositório será atualizado conforme minha evolução e a realização de novos exercícios.
